This is a simple Python project that calculates a student's total marks, average, highest & lowest subject score, and assigns a grade based on performance.

⚙️ Features
Takes input for student name and marks
Validates marks (0–100 range)
Calculates:
Total marks
Average marks
Highest subject score
Lowest subject score

Assigns grade based on average:
A (90–100)
B (75–89)
C (60–74)
D (40–59)
Fail (<40)
